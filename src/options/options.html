Notionish

Choose which Google surfaces get the Notion-ish focus treatment.

Text size

Docs draws body text into a canvas, so nothing in a stylesheet can set its size. Browser zoom can: it changes the resolution Docs renders against, so the canvas is repainted larger rather than scaled up, and the text stays sharp. This is the setting that closes most of the gap to a Notion page. It applies per tab, only while focus mode is on, and it is not the site-wide zoom Firefox remembers for you — switching Notionish off puts the tab back to 100%. Sheets is left alone: the same zoom would work, but it would mean seeing fewer rows, which is a different kind of change.

Typography

Docs paints text to a canvas and places each run of formatting at a coordinate computed from the original font's measurements. Inter measures differently, so runs overlap — bold text collides with the words either side of it and lines become genuinely hard to read. This is not a subtle reflow. It stays here because it proves canvas text is reachable at all, not because it is usable. Nothing here affects anyone else's view of the document.

On any enabled tab, press Alt+Shift+N — or use the toolbar button — to bring the full Google UI back without disabling the extension.
